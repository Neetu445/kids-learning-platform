#  Kids AI Learning App

An interactive full-stack learning platform built for kids to learn through quizzes, topics, and gamified progress tracking.

---

##  Features

-  User Authentication (Register/Login)
-  Topic-based Learning System
-  Interactive Quiz System
-  Real-time Score & XP System
-  Level Progression System
-  User Profile with Avatar
- Progress Tracking
- Instant Answer Validation
- Progress Saved in Backend

---

##  Tech Stack

### Frontend
- React.js
- Axios
- Framer Motion
- CSS (Custom Styling)

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Bcrypt.js

##  How to Run Locally

### 1. Clone repo
    git clone <https://github.com/Neetu445/kids-learning-platform>

### 2. Install frontend
  cd frontend
  npm install
  npm start


### 3. Install backend
     cd backend
     npm install
     node server.js
